# Hospital Identity & Access Integration Project

Welcome to a beginner-friendly, hands-on project for learning how enterprise systems integrate inside a simulated hospital environment.

## Your Mission

You are helping a fictional hospital build its identity infrastructure and integrate a new software application into the environment.

Throughout the project, you will work with:

- VMware and virtual machines
- Windows Server 2022
- Active Directory
- DNS and networking
- Identity and Access Management
- SMB and file permissions
- Ubuntu Linux
- LDAP
- PowerShell
- Software integration
- Troubleshooting
